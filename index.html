CleanFrame

A data-cleaning engine you can actually put in a pipeline. An LLM writes the plan once; the plan compiles to a YAML recipe that replays over next month's file in pure pandas: no API calls, same answer every time. When the schema drifts it stops and tells you, instead of quietly corrupting the column.

MoM AI: Minutes of Meeting

Drop in a recording, get back minutes. FFmpeg normalizes the audio, a Celery worker routes it to one of six speech-to-text backends, including Whisper on your own machine, and an LLM returns the summary, the decisions and the action items. Both layers swap at runtime, from a dropdown.
